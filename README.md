# Ôn Tiếng Anh 8 giữa học kì 1 (Global Success, Unit 1-3)

Web tĩnh gồm từ vựng có loa, phát âm, ngữ pháp, đề luyện tập tự chấm và đồng hồ thi thử 60 phút.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub, tải toàn bộ file trong thư mục này lên (index.html ở thư mục gốc).
2. Vào Settings > Pages > Source: chọn branch main, thư mục / (root), bấm Save.
3. Sau 1-2 phút, trang chạy tại https://TEN-TAI-KHOAN.github.io/TEN-REPO/

## Chạy thử trên máy
Mở file index.html bằng Chrome. Cần Internet để tải font chữ, giọng đọc dùng engine có sẵn của trình duyệt.

## Chỉnh nội dung
- data.js: từ vựng, đề luyện tập, đáp án và lời giải.
- app.js: giao diện, bài giảng ngữ pháp, logic chấm điểm.
- style.css: giao diện.

Lưu ý: lời thoại phần Listening trong data.js (L1_TRANSCRIPT, L2_TRANSCRIPT) do người soạn viết để luyện nghe, hãy thay bằng bài nghe thật nếu có.
