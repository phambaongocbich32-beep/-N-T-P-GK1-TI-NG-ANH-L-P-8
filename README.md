# Ôn Tiếng Anh 8 giữa học kì 1 (Global Success, Unit 1-3)

Trang web ôn tập gồm: từ vựng có loa, phát âm, ngữ pháp, đề luyện tập tự chấm và đồng hồ thi thử 60 phút.
Toàn bộ trang nằm trong MỘT file `index.html` (không cần file nào khác).

## Đưa lên GitHub Pages
1. Tạo repository mới, tải 3 file `index.html`, `README.md`, `.nojekyll` lên (để ở thư mục gốc, không để trong thư mục con).
2. Vào Settings > Pages > Source: chọn branch `main`, thư mục `/ (root)`, bấm Save.
3. Chờ 1-2 phút rồi mở https://TEN-TAI-KHOAN.github.io/TEN-REPO/

Lưu ý: phần Listening dùng lời thoại soạn sẵn, giọng đọc do trình duyệt (Chrome, Edge, Safari). Cần Internet để tải font chữ.
